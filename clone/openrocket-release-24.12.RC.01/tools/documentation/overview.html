Flight computer and MIT simulation extensions

The flight-computer runtime now lives under edu.mit.rocket_team. Its existing functional subpackages are retained. The former .zephyrus namespace segment has been removed; direct imports must use the new names.

This reference includes private implementation methods, the graphical FC designer, controller blocks, recovery, telemetry/replay, ensembles, motor batches and 3D plotting. Selected existing OpenRocket engine classes are included to make integration links navigable.

See the architecture guide for editable UML diagrams, clock/coordinate contracts and regeneration instructions.

Simulation time is virtual. Custom Java boards do not model communications contention or shared processor timing. Hardware adapters such as camera, flash and power are logical models. The documentation describes the implementation; it does not qualify physical flight hardware.
